Sistema de venta de hardware.

## Características principales

- **Autenticación**: Registro, login y gestión de sesiones con JWT seguro
- **Gestión de productos**: CRUD completo con búsqueda, control de stock y activación/desactivación
- **Categorías**: Organización de productos por categorías con mantenimiento integrado
- **Módulo de ventas**: Registro de ventas, múltiples métodos de pago, tipos de entrega y seguimiento de historial

## Stack tecnológico

- Backend: .NET 8 + Entity Framework Core + SQLite
- Frontend: HTML, JavaScript (vanilla), Tailwind CSS, Font Awesome
